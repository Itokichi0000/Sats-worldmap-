Blink

Blink のダッシュボード（dashboard.blink.sv）→ API Keys で、権限を Read だけにして作ります（Receive・Write は要りません）。 キーはこのブラウザにだけ置き、サイトのファイルには入りません。スクリーンが受け取った支払いを読むのに使います。 


    

      

      

        支払いページ
        
        
本番の前に、自分のスマホで 21 sats を投げて、スクリーンに出るまでを確かめてください。

      

    

  


  

    
 ラウンド

    

      
      
    

    

    

      
      
    

    
スクリーンでスペースキーを押しても、始める・終えるができます。

  


  

    
 演出

    

      
      
    

    
    
    
    
    
    
↑ オンにすると、この Blink のアカウントに入ったお金はすべてスクリーンに出ます。イベント専用のアカウントのときだけオンにしてください。

  


  

    
 メッセージ

    
    
    
URL・インボイス・npub は自動で 🔗 に置き換えます。よくない言葉もいくつかは最初から出しません。

    
最近の 1 投（隠すと、名前とひとことがスクリーンから消えます。sats は数えたまま）

    

  


  

    
 テスト

    
お金を動かさずに、スクリーンの演出だけを確かめます（「テスト」の印が付きます）。

    

      
      
      
      
    

    

      
      
    

  


  

    
 記録（Nostr）

    

      1 投ごとに「地域・sats・ニックネーム・ひとこと・時刻」を Nostr のリレーに出します（NIP-78）。正しい記録は Blink の入金履歴で、これはその写しです。
      パソコンが壊れても、ここから「隠した」「どのラウンドか」を戻せます。リレーに出したものは公開され、消せません（隠したもの・NG ワードのものは、名前とひとことを出しません）。
    

    
    
スクリーンを開くと、記録の状態がここに出ます

    
    

      
      
    

    
別のパソコンで同じ記録を続けるときは、ここで書き出した nsec を、そちらの管理画面で読み込みます。読むだけなら npub だけで足ります。

    
  


  

    
 作り直す

    

      Blink の入金履歴を読み直して、集計を作り直します。ブラウザのデータが消えたとき・別のパソコンに替えたときに使います。
      金額・地域・名前は Blink の履歴（インボイスのメモ）から、「隠した」「どのラウンドか」は Nostr の記録から戻します。
    

    

      
      
    

    

      
      
    

    

      
    

    

  


  

    
 イベント

    

      
      
    

    
「最初からやり直す」は、集計とラウンドを 0 に戻し、いまより前の入金を数えなくなります（Blink のお金はそのまま）。
