# Sats World Map（モックアップ / ダミーデータ版）

ライトニングネットワークで特定のLightningアドレスに sats を送ると、世界地図・日本都道府県地図が
カラフルに更新される「ライブ寄付マップ」の **見た目確認用モックアップ** です。

⚠️ **このバージョンはLNbits等のバックエンドには接続されていません。** 表示されている送金データは
すべてダミー（固定データ＋デモボタンでの手動発火）です。実際のライトニング決済とは連動していません。

---

## 1. 現在実装済みの機能

- **世界地図（国別）** と **日本地図（都道府県別）** の2枚を amCharts 5（無料版）で構築し、常に**左右並列表示**
- 各地図カード右上の「⤢」ボタンでその地図だけを全幅フォーカス表示に切替可能。フォーカス中は上部に「両方表示に戻す」ボタンが表示され、いつでも並列表示に戻せる
- 送金額に応じたヒートカラー（暗い青 → オレンジ）で地域を塗り分け（0satsの基準点を常にデータに含めることで、少額の受信でもベース色に埋もれず必ず視認可能）
- 新規送金が発生した際の **パルス（点滅）アニメーション** と **中央上部のトースト通知**
- ヘッダーの統計カード（総送金件数／総sats／対応地域数）
- サイドバーの **最新の送金フィード**（直近25件までスクロール表示）
- サイドバーの **地域別ランキング**（送金額の多い順、バーで可視化）
- **デモ操作パネル**：USA / 東京 / 北海道の固定ボタン + ランダム送金ボタンで、送金発生時の挙動をその場で確認可能
- 下部の **QRコード風ストリップ**（見た目のみ。実際のQR生成はまだ未実装）
- レスポンシブ対応（タブレット・スマホ幅で1カラムに変化）

## 2. ファイル構成 / エントリーポイント

```
index.html          唯一のページ（パラメータなし）
css/style.css        全スタイル
js/dummy-data.js      ダミー送金データ（本番では tables/donations の取得結果に置き換え予定）
js/map.js            amCharts5 の世界地図・日本地図構築＆更新ロジック（SatsMap 名前空間）
js/app.js            画面全体のロジック（フィード・ランキング・統計・デモボタン制御）
```

このプロジェクトには他のURLパス／パラメータはありません（単一HTMLページ）。

---

## 3. データモデル（将来のTable API想定）

現在はダミー配列（`js/dummy-data.js`）ですが、本番では以下のスキーマの `donations` テーブルを
ポーリングして同じ形のオブジェクトを流し込む想定で設計しています。

```
donations
- id
- region_type   : "country" | "jp_prefecture"
- region_code   : "US" (ISO-2) または "JP-13" (ISO 3166-2:JP、都道府県)
- region_name   : 表示名 (例: "Tokyo")
- flag          : 表示用アイコン/絵文字
- amount_sats   : number
- memo          : text
- payment_hash  : LNbits由来の一意キー（重複防止用、未実装）
- status        : "pending" | "paid"
- created_at
```

## 4. まだ実装されていない機能（次のステップ）

1. **LNbits連携**
   - 地域ごとのLightningインボイス（または LNURLp Pay Link）の発行
   - 支払い確定の検知（ポーリング or Webhook相当）
   - 支払い確定時に `donations` テーブルへ1レコード追加
2. **実際のQRコード生成**（現在はプレースホルダーのアイコンのみ）
   - 動的インボイス発行時にQRコード画像/SVGを生成して表示するページ（例: `pay.html?region=JP-13`）
3. **本物の送金データに基づく地図更新**
   - `tables/donations` を定期ポーリングし、未処理レコードが来たら `handleNewTransaction()` を呼ぶ実装への切替
   - 重複処理防止（`payment_hash` のユニーク管理）
4. **日本都道府県コードの全国対応・表記ゆれの整理**（現在はデモに必要な東京・北海道など数件のみ動作確認済み）
5. **大画面運用向けの自動タブ切替**（世界⇔日本を一定時間で自動ローテーションする等、必要であれば）
6. **アクセス制御**（会場内限定表示にしたい場合など、必要であれば別途相談）

## 5. 動作確認方法（現状のモックアップ）

- ページを開くと自動的に初期ダミー3件（USA/東京/北海道）が地図とフィードに反映されます
- サイドバー下部の「デモ操作」パネルの各ボタンを押すと、送金発生時のアニメーション・通知・ランキング更新・統計加算をその場で確認できます
- 世界地図タブ／日本地図タブをクリックして地図を切替できます
