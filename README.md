# Sats World Map ⚡ — ライトニングで地図を灯そう

ビットコインカンファレンスの会場のプロジェクターに映す、合間の時間のミニゲーム。
お客さんがスクリーンの QR をスマホで読み、都道府県か国を選んで Lightning で sats を投げると、
地図がその場で灯り、稲妻・花火・吹き出しが出ます。

元は [fixthemoney/SatsMap](https://github.com/fixthemoney/SatsMap) の見た目のモックアップ（ダミーデータ）。
これに Lightning の本物の支払いと、会場向けの遊びを足しました。

- **サーバーはいりません。** 置くのは HTML・CSS・JS だけで、Nostr（nsite）に上げて公開します
- **受け取りは NWC（Nostr Wallet Connect）。** Coinos・Alby Hub など、NWC に対応したウォレットならどれでも。Nostr のリレー越しにウォレットへ頼むので、サーバーは要りません（Blink にも切り替えられます）
- **スマホの支払いページは、自分のウォレットに「インボイスを作って」と頼みます。** そのための接続は「インボイスを作る・確かめる」だけを許したもの（お金は動かせない）
- **スクリーンは、ウォレットの「受け取った」の知らせで、すぐ地図を灯します。** 取りこぼし用に受け取り履歴も読みます。この接続はスクリーンを映すパソコンのブラウザにだけ置きます

## 1. できること

| | |
|---|---|
| **スマホの支払いページ**（`pay.html`） | 47 都道府県（名物の絵文字つき）か世界の国を選ぶ → 21 / 210 / 2,100 / 21,000 sats か好きな金額 → ニックネームとひとこと（なくてもよい）→「投げる」でウォレットが開く。払うと「届きました！」。選んだ地域と名前は次のために覚える |
| **地図が灯る** | 届いたらその地域へ寄って、金額に応じて演出：100 未満は火花、100〜は稲妻、2,100〜は花火、21,000〜は画面いっぱいの 🐋 WHALE ZAP（画面がゆれる）。地図の色は合計の多さで濃くなる |
| **吹き出し** | その地域の上に、名前とひとことが出る |
| **日本 vs 世界の綱引き** | 都道府県（と日本）に投げた分 vs ほかの国に投げた分 |
| **制覇** | 都道府県 N / 47。初めての地域は「NEW! 初制覇」、47 そろうと「全国制覇！」 |
| **ラウンド** | 合間ごとに 1 ラウンド（長さとゴールは管理画面で）。残り時間・ゴールのバー（25・50・75・100% で知らせ）・いまの MVP。終わると結果の画面（合計・MVP・いちばん灯った地域・最大の 1 投・日本 vs 世界） |
| **札の順番** | 大きな札（クジラ・王座交代・お題クリアなど）は重ならないよう 1 つずつ順に出す |
| **おまけ** | 20 秒以内に続くと 🔥 COMBO、ゾロ目（111・777…）、キリ番（10・21・50・100 投目…）、累計の節目（1,000・2,100・5,000・10,000… sats 突破） |
| **ランキング** | 地域・人・地方・王様を 10 秒ごとに切り替え（タブを押しても切り替わる） |

| **🎯 お題** | 4 分ごと（管理画面で変えられる）に、「まだだれも投げていない 🐫 鳥取県 を灯せ」「近畿の県に 3 投」「ゾロ目で投げろ」「日本以外の国を 3 か国」「ちょうど 21 sats を 3 回」などが出る。達成すると「MISSION CLEAR」と、決めた人の名前。スマホの支払いページにも、お題と残り時間とクリアが出る |
| **🏯 地方対抗** | 北海道・東北・関東・中部・近畿・中国・四国・九州沖縄の 8 地方で競う。ラウンドの結果に「地方対抗の勝者」 |
| **名物の雨** | 100 sats 以上だと、その地域の絵文字（🐙 大阪・🦀 北海道・🗼 東京…、国は国旗）が画面に降る。金額が大きいほど多く |
| **🔥 ラストスパート** | ラウンドの最後の 60 秒は、画面のふちが燃え、演出が 1 段強くなる（21 sats でも稲妻、2,100 sats でクジラ） |
| **呼び込み** | 下の帯に「まだだれも投げていない：🐫 鳥取県 — 最初の 1 投で初制覇！」などを順に出す |
| **効果音** | 合成した短い音（ファイルなし）。ブラウザの決まりで、スクリーンを一度クリックしてから鳴る |
| **管理画面**（`admin.html`） | 受け取り（NWC か Blink）の設定と接続テスト、ラウンドの開始・終了、演出の金額、メッセージの NG ワード・隠す、テストの 1 投、CSV で保存、最初からやり直す |

メッセージは、NG ワードを含むものは出さず、URL・インボイス・npub は 🔗 に置き換えます。名前やひとことに書いた HTML は文字として出します。

## 2. しくみ

```
お客さんのスマホ                      主催者のウォレット（NWC）              会場のパソコン（スクリーン）
 pay.html ──「インボイスを作って」──→  Coinos・Alby Hub など  ──「受け取った」の知らせ──→ index.html
   │      （支払いページ用の接続：        ↑                     （スクリーン用の接続：
   │       make_invoice・lookup_invoice） │                       list_transactions・notifications）
   └── ウォレットアプリで払う ──────────┘                       └→ 説明の地域・名前で、地図を灯す
         （頼みも返事も Nostr のリレー越し。サーバーなし）
```

NWC の接続は 2 つに分けます。

| 接続 | 許すこと | 置き場所 | 漏れたら |
|---|---|---|---|
| ① 支払いページ用 | make_invoice・lookup_invoice **だけ** | スクリーンの QR の URL の `#` のあと（サーバーに送られない）。QR からだれでも読める | あなた宛てのインボイスを作られるだけ |
| ② スクリーン用 | list_transactions・lookup_invoice・notifications | スクリーンを映すパソコンのブラウザだけ | 受け取り履歴が見える |

どちらにも **pay_invoice（支払う）を許さないでください**。管理画面の接続テストは、① で履歴・残高が読めてしまうと「！」で知らせます。

Blink で受け取るときは、スマホのページがキーなしで「受け取る人宛てのインボイス」を Blink に作ってもらい、スクリーンが Read だけの API キーで受け取りを読みます。

インボイスのメモに、地域・ニックネーム・ひとことを入れています（ウォレットにもそのまま出ます）：

```
⚡SatsMap 🗼東京都 from ましゅ ##{"v":1,"r":"jp_prefecture:JP-13","n":"ましゅ","m":"はじめての Lightning！"}
```

スクリーンは、このメモが付いた入金だけを数えます（管理画面で「直接の送金も数える」をオンにしたときを除く）。
本物のお金がウォレットに入ったものだけが地図に出るので、偽の「投げた」は作れません。

### 記録はどこにあるか

| 記録 | 中身 | 役目 |
|---|---|---|
| **ウォレットの入金履歴** | 金額・日時・インボイスの説明（地域・ニックネーム・ひとこと） | **正しい記録。** お金が入った証拠 |
| **Nostr のリレー** | 1 投ごとに、地域・sats・ニックネーム・ひとこと・時刻・ラウンド・隠したか（NIP-78、kind 30078） | 写し。パソコンが替わっても「隠した」「どのラウンドか」を戻せる。あとでだれでも結果を見られる |
| スクリーンのブラウザ | 集計に使う写し（localStorage） | 画面を描くため。CSV でも保存できる |

**だれが投げたか（送り主のアドレス）は、Lightning の仕組み上わかりません。** わかるのは、お客さんが自分で書いたニックネームだけです。

Nostr の記録は、スクリーンのブラウザで作る**記録専用の鍵**で署名します（お金・ほかのアカウントとは関係ない使い捨ての鍵）。

```
kind 30078（置き換えのできるイベント。d ごとに最新の 1 つ）
  1 投   d = "<イベント>:<取引 id（NWC は payment hash）>"   content = {"v":1,"id":…,"at":…,"sats":2100,"r":"jp_prefecture:JP-13","n":"ましゅ","m":"…","round":1,"hidden":false,"hash":…}
  全体   d = "<イベント>:meta"               content = {"v":1,"kind":"meta","since":…,"rounds":[…],"eventName":"…"}
  t タグ = "satsmap"・"satsmap-<イベント>"
```

- テストの 1 投は出しません。隠したもの・NG ワードを含むものは、名前とひとことを空にして出します（隠すと、空にした版で置き換えます）
- **リレーに出したものは公開され、消せません。** 支払いページにもそう書いています。出したくないときは、管理画面で「Nostr に記録を出す」をオフ
- スクリーンの QR の URL には、記録の鍵（`k=npub…`）とイベント（`s=…`）が入ります（リレーを変えたときは `rl=` も）。スマホの支払いページは、これで「いまの会場」を読みます。記録をオフにすると QR から外れ、「いまの会場」も出なくなります

## 3. 準備するもの

1. **NWC に対応したウォレット**。**イベント専用のウォレットをおすすめします**（スクリーンは受け取った支払いを読むので）
   - **Coinos**（https://coinos.io）：預かり型・無料・ブラウザだけで使える。いちばん手軽
   - **Alby Hub**（https://albyhub.com）：自分で鍵を持つ型。自分のパソコンで動かすか、Alby Cloud（有料）に置く
   - ほか NWC に対応したもの。日本から作れて受け取れるかは、それぞれのサービスで確かめてください
2. **接続（アプリの接続）を 2 つ**作り、`nostr+walletconnect://…` を控える
   - ① 支払いページ用：**make_invoice（インボイスを作る）・lookup_invoice（確かめる）だけ**
   - ② スクリーン用：**list_transactions（履歴を読む）・lookup_invoice・notifications（知らせ）**
   - ウォレットによっては細かく選べず「受け取りだけ（Receive only）」などの名前になっています。**支払いを許さない**ものにしてください
3. 上げるとき：Mac に Node.js と、署名アプリ（Clave など）

Blink で受け取るときは、Blink のアカウントと、ダッシュボード（https://dashboard.blink.sv）→ API Keys で **Read だけ**の API キーを作ります。

## 5. Nostr（nsite）に上げる

```bash
npm install
```

```bash
npm run deploy
```

1. `nostrconnect://…` と QR（`.nsite/nostrconnect.svg`）が出るので、署名アプリ（Clave・Amber・nsec.app など）で読む。秘密鍵は打ち込まない
2. 署名の確認が 2 回出るので承認する（ファイルを Blossom に置く許可 kind 24242、サイトの一覧 kind 35128）
3. 出た URL を開く

いま公開しているもの（2026-10-31）：
スクリーン https://0alv7lzdlnag1g30cf2vu7nwn9zohoftnmhwp4x5zarcdqpvq3satsmap.nsite.lol/ ・ 支払いページ …/pay.html ・ 管理画面 …/admin.html
（ファイルは blossom.primal.net に置いた。blossom.band は HTML・JS・フォントを、cdn.satellite.earth は有料の人以外を断る）

NIP-5A の**名前つきサイト**（kind 35128、`d=satsmap`）として上げるので、同じ npub のいちばん上のサイト（kind 15128）は上書きしません。
開く場所は `https://<公開鍵の 36 進数 50 桁>satsmap.nsite.lol/`（最後に上げたときの URL は `.nsite/last-deploy.json`）。
スクリーン・`/admin.html`・`/pay.html` が開けます。置き場所（リレー・Blossom サーバー）は `.nsite/config.json`。
bunker:// でつなぐときは `SATSMAP_BUNKER='bunker://…' npm run deploy`。

支払いページの URL をポスターなどに刷るときは、先に `js/config.js` の `nwcPay` に ① 支払いページ用の接続を書いてから上げてください
（書かないときは、管理画面で入れたものがスクリーンの QR の URL の `#` のあとに付きます）。Blink のときは `blinkUsername`。イベント名も `js/config.js` の `eventName` に書けます。

## 6. 会場で

1. スクリーンを映すパソコンで、Chrome で上げたサイトの URL を開く
2. 同じブラウザで `admin.html` を開く（スクリーンで `A` を押しても開く）→「受け取り」で NWC を選び、① 支払いページ用と ② スクリーン用の接続を入れて **接続テスト**。✓ が 5 つ並び、✗・！ がなければ OK
3. 自分のスマホでスクリーンの QR を読み、**21 sats を投げて、スクリーンに出るまで**を確かめる（リハーサル）
4. 管理画面の「テストの記録を消す」、必要なら「最初からやり直す」
5. スクリーンを一度クリック（音を出すため）→ `F` で全画面
6. 合間になったら `Space`（または管理画面の「ラウンドを始める」）。時間が来ると結果が出る。次の合間にまた `Space`

| キー（スクリーン） | |
|---|---|
| `F` | 全画面 |
| `Space` | ラウンドを始める・終える |
| `M` | 音を出す・止める |
| `1` / `2` / `0` | 世界だけ / 日本だけ / 両方 |
| `A` | 管理画面 |
| `D` | デモの 1 投（デモのときだけ） |
| `Esc` | 結果の画面を閉じる |

記録はそのパソコンのブラウザの中にあり、開き直しても続きから。閉じていたあいだの入金も、開いたときに数えます（演出はなし）。

### パソコンが壊れた・別のパソコンに替える

1. 前のパソコンの管理画面で「鍵を書き出す（nsec）」を控えておく（**本番の前に**）。控えがなくても、金額・地域・名前はウォレットの履歴から戻せます
2. 新しいパソコンで、スクリーンと管理画面を開き、NWC の接続（または Blink のユーザー名と API キー）を入れる
3. 「記録（Nostr）」→「鍵を読み込む」で控えた nsec を貼る
4. 「作り直す」→「Nostr でイベントを探す」→ イベントを選ぶ（数え始めの時刻も入る）→「履歴から作り直す」

ブラウザのデータを消してしまっただけのときは、4 だけで戻せます（時刻はイベントを始めた時刻に）。

## 7. 安全とお金のこと

- API キーは、スクリーンを映すパソコンのブラウザ（localStorage）の中だけ。サイトのファイル・Nostr には入りません。終わったら管理画面の「キーを消す」
- 記録の鍵（nsec）も、そのブラウザの中だけ。お金とは関係なく、漏れても「この記録に書き足せる」だけです
- API キーは **Read だけ**で作る。漏れても残高と履歴が見えるだけで、お金は動かせません
- 管理画面は URL を知っていればだれでも開けますが、キーも記録もその人のブラウザにしかないので、会場のスクリーンには何もできません
- 「投げた sats は返金できない」「景品・賞品はない」と支払いページに書いています。**投げた結果で景品が当たる形にはしないでください**（賭博・景品表示法にかかるおそれがあります）
- ニックネーム・ひとことはインボイスの説明に入るので、ウォレットの履歴に残ります
- NWC の接続は、どちらも**支払いを許さない**ものにする。① 支払いページ用は QR に載るので、だれでも読めます

## 8. 確かめていないこと【要確認】

本番の前に、管理画面の接続テストと、自分のスマホで 21 sats を投げるリハーサルで確かめてください：

- **NWC**：自動の確認は、NIP-47 どおりに答えるウォレットのまね（NIP-44 と NIP-04 の両方）で通しています。本物のウォレット（Coinos・Alby Hub など）では、まだ試していません。特に
  - インボイスの説明（description）が、受け取り履歴（list_transactions）と知らせ（notifications）にそのまま入るか（入らないと、地域が「⚡」になる）
  - 「受け取った」の知らせ（notifications）に対応しているか（していなければ、一覧を 8 秒ごとに読むので少し遅れる）
  - 接続ごとに許すこと（make_invoice だけ、など）を選べるか
- **Blink**（切り替えたとき）：本物の API の名前・入力・ブラウザからの呼び出し（CORS）は 2026-10-31 に確かめました。受け取りのメモが取引の一覧に出るかは、まだ試していません
- 会場の Wi-Fi が不安定なときは、スクリーンのパソコンをスマホのテザリングにつなぐと安心
- 記録を出すリレー（既定：yabu.me・r.kojira.io・nos.lol・relay.damus.io・relay.primal.net）が kind 30078 を受け取るか。管理画面の「記録（Nostr）」に「✓ すべてリレーに出しました」が出れば OK
